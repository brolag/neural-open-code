# Archived Neural OpenCode 1.9.0 surface

This tree is **unsupported**. It is kept so history remains readable after the
2.0 breaking cleanup.

Do not present these files as the current product. Do not load
`dot-opencode/` as the supported OpenCode plugin. The supported surface lives
at `plugins/neural-open-code/` on the repository root.

Removed from the supported path (non-exhaustive):

- Agentic course (`/course`)
- Neural Squad and related commands
- Neural loops (`/loop`)
- TTS / ElevenLabs
- Multi-AI mesh (`/pv-mesh`, `/ai-collab`)
- KPI, Compute Advantage, and cost trackers
- Memory / expertise / remember-recall product
- Custom installers and one-liner home-directory setup
- Output styles, status lines, and extra command/agent packs

Lyft, WordPress, and MCP-dependent features were never part of the 2.0 port
and stay deferred.
